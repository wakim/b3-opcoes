## Implementação

- `frontend/src/styles.css` centraliza a escala em tokens `@theme` (`--text-*`,
  `--leading-*`). Os valores são **px**, não `rem`: o `html` continua em 13,5 px
  no mobile e `1rem` não poderia representar 16 px sem alterar espaçamentos.
- A aplicação desktop usa somente utilitários `lg:`. Os três blocos
  `@media (min-width: 1024px)` de tipografia do F5-F foram removidos.
- Não há `zoom`, `transform: scale`, tamanho arbitrário espalhado nem seletor
  CSS desktop novo. Sans de sistema e mono tabular foram preservados.
- Button, Input, Select, Table e Dialog gerados pelo shadcn usam os mesmos
  tokens. Nenhum primitive fica em `text-sm`; Dialog usa corpo 16/título 22 e
  Table usa 14/13. Os tokens semânticos de cor do shadcn apontam para a paleta
  grafite existente.
- O checkout não tinha F8 nem relatório anterior. F8.1 foi configurada agora
  (`components.json`, alias `@`, `src/components/ui`). F8.2/F8.3 — migração
  completa das telas e remoção do CSS artesanal redundante — continuam pendentes.
